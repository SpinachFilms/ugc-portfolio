# Paulo Loyo — UGC Portfolio

Live site: [spinachfilms.github.io/ugc-portfolio](https://spinachfilms.github.io/ugc-portfolio)

Personal UGC portfolio showcasing brand video campaigns across fashion, lifestyle, tech, food, and luxury categories. Built with HTML, CSS, and hosted on GitHub Pages.
